## SELECTED WORK

### ClaimSight India

**AI-powered vehicle insurance claim assessment system**

Processes vehicle damage images using computer vision and multimodal AI to produce structured, auditable damage assessments — built to replace manual claim review with a reproducible pipeline.

<div align="center">

`Vehicle Image` → `Damage Segmentation` → `Part Detection` → `Damage-to-Part Mapping` → `Damage Percentage` → `Severity Assessment` → `Structured Report`

</div>

**Stack:** Python · YOLO Segmentation · Computer Vision · PyTorch · React · Node.js · Supabase

**Repository:** [github.com/bhavayvasudev/ClaimSightIndia](https://github.com/bhavayvasudev/ClaimSightIndia)
